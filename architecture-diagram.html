System Architecture

Three frames: Clients — Services — Data. Cylinder store icons.

Clients

  • • Web App (browser / SPA)
  • • Mobile App (iOS / Android)
  • • Both call API Gateway over HTTPS

Services

  • • API Gateway — routing, rate limits
  • • Auth Service — JWT / OAuth
  • • Orders Service — business logic
  • • Notification Worker — MQ consumer

Data Stores (Cylinders)

  • • Postgres — primary DB (orders read/write)
  • • Redis Cache — order cache
  • • Message Queue — pub/sub bus
